# HACKRUSH 2026 | TECH4HACK

### Think. Build. Transform.

An organiser-focused event dashboard for **HackRush 2026**, designed to bring event information, innovation tracks, team insights and competition updates together in one workspace.

## Project Overview

The Tech4Hack dashboard provides a centralised interface for exploring the HackRush 2026 journey. It presents important event milestones, innovation domains, team information, analytics, leaderboard standings and announcements through a clean, responsive interface.

## Key Features

- **Overview Dashboard** – Event highlights, key statistics, upcoming milestones and innovation track previews.
- **Event Timeline** – A structured view of important dates, competition stages and preparation milestones.
- **Innovation Tracks** – Detailed information about five innovation domains, including project ideas, relevant technologies and suggested development journeys.
- **Team Hub** – Team directory with search, track filters, status filters and submission progress indicators.
- **Analytics** – Visual representation of track participation, submission status and competition-stage statistics.
- **Leaderboard** – Ranked team presentation with a top-three podium and performance table.
- **Announcements** – Organised event updates with pinned announcements, categories and priority indicators.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/janvijiya398-ui/hackrush-2026-tech4hack.git
```

Navigate to the project directory:

```bash
cd hackrush-2026-tech4hack
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the dashboard.

### Production Build

To generate an optimised production build:

```bash
npm run build
```

The production-ready files are generated in the `dist` directory.

## Design Approach

The dashboard follows a clean emerald-and-white visual identity, with a focus on:

- Clear information hierarchy
- Consistent navigation
- Structured data presentation
- Responsive layouts
- Reusable UI components
- Readable analytics and progress indicators
